## 🎯 প্রজেক্ট পরিচিতি | Project Overview

**রক্তদাতা** প্ল্যাটফর্মটি বাংলাদেশের ৬৪টি জেলায় জরুরি রক্তের সংকট মোকাবেলায় একটি সম্পূর্ণ ডিজিটাল সমাধান হিসেবে তৈরি করা হয়েছে। এটি একটি ফুল-স্ট্যাক, মোবাইল-ফার্স্ট ও ডেস্কটপ-নেটিভ ওয়েব অ্যাপ্লিকেশন — যা রক্তদাতা, রক্তগ্রহীতা, হাসপাতাল ও অ্যাম্বুলেন্স সেবাকে একটি প্ল্যাটফর্মে একত্রিত করে।

**মূল লক্ষ্যসমূহ:**
- জরুরি রক্তের প্রয়োজনে কোনো মধ্যস্বত্বভোগী বা আর্থিক খরচ ছাড়াই সরাসরি রক্তদাতা খুঁজে দেওয়া
- রক্তদানের ইতিহাস, স্বাস্থ্য তথ্য ও বায়োলজিক্যাল রিকভারি ডিজিটালি সংরক্ষণ করা
- হাসপাতাল ও ব্লাড ব্যাংকের রিয়েল-টাইম রক্তের স্টক ট্র্যাকিং নিশ্চিত করা
- বাংলা ও ইংরেজি উভয় ভাষায় স্বাচ্ছন্দ্যময় ব্যবহারকারী অভিজ্ঞতা প্রদান
- **সম্পূর্ণ ফ্রি টিয়ারে পরিচালনা**: কোনো পেইড এসএমএস গেটওয়ে বা অতিরিক্ত সার্ভার খরচ ছাড়াই চালনাযোগ্য

## 🌐 নেটিভ ব্রাউজার API সমূহ | Native Browser APIs

রক্তদাতা প্ল্যাটফর্মটিতে কোনো অতিরিক্ত থার্ড-পার্টি লাইব্রেরি ছাড়াই ৬টি শক্তিশালী নেটিভ ব্রাউজার API সরাসরি ব্যবহার করা হয়েছে:

| Native API | ফাইল | বিস্তারিত ব্যবহার |
|---|---|---|
| **Web Audio API** | `lib/audioUtils.ts` | Oscillator-ভিত্তিক সিন্থেসাইজড চাইম সাউন্ড। OTPlessকোনো অডিও ফাইল লোড না করে JavaScript দিয়েই নোটিফিকেশন সাউন্ড তৈরি করা হয় |
| **Web Share API** | `components/profile/` | WhatsApp, Telegram, Facebook, SMS-এ ডিরেক্ট নেটিভ শেয়ার। ব্রাউজারের OS-লেভেল শেয়ার শিট ব্যবহার করে |
| **Web Push Notification API (VAPID)** | `lib/services/pushNotificationService.ts` | নেটিভ ব্রাউজার পুশ নোটিফিকেশন। VAPID কী দিয়ে সুরক্ষিত সাবস্ক্রিপশন ম্যানেজমেন্ট |

### অথেন্টিকেশন পদ্ধতি | Auth Methods

1. **গুগল (Google) OAuth** — ১-ক্লিক সোশ্যাল লগইন, কোনো পাসওয়ার্ডের ঝামেলা নেই

### বিশেষ নিরাপত্তা ব্যবস্থা | Security Measures

- **বাধ্যতামূলক মোবাইল নম্বর**: রেজিস্ট্রেশন এবং সোশ্যাল লগইনের সময় বাংলাদেশি ১১ ডিজিটের (`০১X-XXXXXXXX`) সচল মোবাইল নম্বর বাধ্যতামূলক সংগ্রহ করা হয়, কারণ রোগীর স্বজনকে তাৎক্ষণিক ডোনারকে কল করতে হয়
- **ডুপ্লিকেট ফোন প্রতিরোধ**: `profiles.phone_number` টেবিলে `UNIQUE CONSTRAINT` দেওয়া আছে, একই ফোন নম্বর দিয়ে দুটো অ্যাকাউন্ট তৈরি সম্ভব নয়
- **localStorage Persistence**: Auth state `roktodata_auth_user_v1` কী দিয়ে localStorage-এ সংরক্ষিত
- **SSR Hydration Safety**: `React.useSyncExternalStore` ব্যবহার করে সার্ভার ও ক্লায়েন্টের মধ্যে স্টেট মিসম্যাচ শূন্যে নামিয়ে আনা হয়েছে
- **`complete_contact` অনবোর্ডিং ফ্লো**: সোশ্যাল লগইনকারীরা প্রথমবার ফোন ও ব্লাড গ্রুপ কমপ্লিট করার আগে কোনো ফিচার ব্যবহার করতে পারবেন না
- **ফ্রি পাসওয়ার্ড রিকভারি**: পাসওয়ার্ড ভুলে গেলে ইমেইলে সুরক্ষিত রিসেট লিংক পাঠানো হয়

1. [Google Cloud Console](https://console.cloud.google.com/) → নতুন OAuth Client ID তৈরি
2. Authorized redirect URIs: `https://<YOUR-PROJECT-ID>.supabase.co/auth/v1/callback`
3. Supabase Dashboard → **Authentication** → **Providers** → **Google** → Client ID ও Secret পেস্ট

**Facebook OAuth:**
1. [Meta for Developers](https://developers.facebook.com/) → নতুন অ্যাপ তৈরি → Facebook Login যোগ
2. Valid OAuth Redirect URIs: `https://<YOUR-PROJECT-ID>.supabase.co/auth/v1/callback`
3. Supabase Dashboard → **Authentication** → **Providers** → **Facebook** → App ID ও Secret সেভ

**Email Auth:** Supabase-এ ডিফল্টভাবেই সক্রিয় — কোনো অতিরিক্ত কনফিগারেশনের প্রয়োজন নেই।

## 🚀 ইন্সটলেশন ও রান | Installation & Running

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/your-username/roktodata.git
cd Roktodata

# ২. Node.js ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ৩. এনভায়রনমেন্ট ফাইল সেটআপ করুন
cp .env.example .env.local
# .env.local ফাইলে Supabase ক্রেডেনশিয়াল ও VAPID কী পূরণ করুন

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# ৫. প্রোডাকশন বিল্ড
npm run build

# ৬. প্রোডাকশন সার্ভার চালু করুন
npm start

# ৭. কোড লিন্ট চেক
npm run lint
```

ব্রাউজারে **[http://localhost:3000](http://localhost:3000)** ওপেন করুন।

> **💡 টিপ:** Supabase ছাড়াও অ্যাপটি চলবে! `lib/data.ts` থেকে সমৃদ্ধ অফলাইন সিড ডেটা স্বয়ংক্রিয়ভাবে লোড হবে।

## 🏗️ আর্কিটেকচারাল প্যাটার্ন | Architectural Patterns

| প্যাটার্ন | বিবরণ |
|---|---|
| **SSR Hydration Safety** | `React.useSyncExternalStore` + কাস্টম ব্রডকাস্ট চ্যানেল দিয়ে সার্ভার ও ক্লায়েন্ট স্টেট মিসম্যাচ শূন্যে নামানো হয়েছে — হাইড্রেশন এরর নেই |
| **Offline-First Architecture** | Supabase অনুপলব্ধ হলে `lib/data.ts` থেকে সমৃদ্ধ সিড ডেটা ফলব্যাক হিসেবে ব্যবহৃত হয়, অ্যাপ সম্পূর্ণ সচল থাকে |
| **Seamless Scroll Engine** | `overflow-x: clip` + `scroll-behavior: smooth` — কোনো হরিজন্টাল ওভারফ্লো বা লেআউট শিফট নেই |
| **Adaptive Font Scaling** | `≥1700px` ভিউপোর্টে `--large-screen-scale: 1.06` — আল্ট্রা-ওয়াইড স্ক্রিনে চোখের ক্লান্তি কমায়। ব্যবহারকারীর 100%/125%/150% পছন্দের সাথে গুণিত হয় |
| **Desktop Constraint** | `max-w-[1560px]` — 4K ডিসপ্লেতে কন্টেন্ট অতিরিক্ত প্রসারিত হয় না |
| **Zero-Leak Git Security** | `.gitignore` দিয়ে `.env.local`, API কী, লগ ও OS ক্যাশ ফাইল GitHub-এ যাওয়া সম্পূর্ণ রোধ |
| **RBAC Inventory Control** | হাসপাতাল স্টক আপডেট শুধুমাত্র `hospital_operator` বা `admin` রোলের ব্যবহারকারী করতে পারবেন |
| **Phone Privacy System** | ডোনারের ফোন নম্বর ম্যাচ নিশ্চিত হওয়ার আগে মাস্ক করা থাকে (`01712-XXX678`); `privacy_hide_phone` ফ্ল্যাগ DB-তে সংরক্ষিত |
| **Duplicate Phone Prevention** | রেজিস্ট্রেশন বা প্রোফাইল কমপ্লিটের আগে `profiles` টেবিলে ফোন নম্বর অনন্যতা চেক করা হয় |
| **localStorage Persistence** | Auth user, বুকমার্ক, সক্রিয় রিকোয়েস্ট ID ও ভাষা পছন্দ localStorage-এ সংরক্ষিত |

## 🗺️ জিও-লোকেশন ডেটা | Geo-Location Data

`lib/geo/bangladeshGeoData.ts` ফাইলে বাংলাদেশের সম্পূর্ণ ভৌগোলিক ডেটা:

- প্রতি জেলার সম্পূর্ণ **উপজেলার তালিকা**
- **Haversine Distance Calculator**: দুটি GPS পয়েন্টের মধ্যে সরাসরি দূরত্ব (কিমি) গণনা
